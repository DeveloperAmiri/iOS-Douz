# Security Policy

## Reporting a vulnerability

Found a security issue in **iOS-Douz**? Please **do not** open a public issue.

Instead, email **dev.developeramiri@gmail.com** with:

- a description of the vulnerability,
- steps to reproduce (or a PoC),
- the version/commit you tested.

You will get a first response within **72 hours**. If the report is accepted,
a fix will be prioritized and you will be credited in the release notes
(unless you prefer to stay anonymous).

## Supported versions

Only the latest `main` branch is supported with security updates.
