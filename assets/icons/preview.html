Icon reference sheet

Every icon in iOS-Douz is drawn from scratch in the SF Symbols language: a 24×24 viewBox, one uniform 1.75 stroke, rounded caps and joins, no fills. Icons use currentColor, so they adapt to any theme. The same artwork is embedded in js/icons.js.
