# Contributing to iOS-Douz

Thanks for your interest in contributing! 🎉

## How to contribute

1. **Fork** the repo and create a branch: `git checkout -b feat/my-change`
2. Make your change with clear, focused commits.
3. Make sure checks pass:
   - Python projects: `pytest -q`
   - Node projects: `npm run lint` (and `npm test` / `npm run build` if present)
   - Static sites: keep asset paths **relative** so GitHub Pages keeps working.
4. Open a **pull request** describing what changed and why.

## Guidelines

- Keep PRs small and focused — one feature/fix per PR.
- Match the existing code style; no drive-by reformatting.
- Add or update tests/docs when behavior changes.
- Be kind and constructive in reviews — no harassment of any kind is tolerated.

By contributing you agree your work will be released under the repo's MIT license.
